# 🧱 Artikelverwaltung mit Factory Method Pattern (Java)

Dieses Projekt wurde im Rahmen des Moduls **„Objektorientierte Programmierung (OOP)“**  
an der **Hochschule Bochum** entwickelt.  
Es demonstriert die Anwendung des **Factory Method Design Patterns**  
zur flexiblen Erzeugung von Reader- und Writer-Objekten in Java.

---

## 🎯 Ziel des Projekts
Das Ziel war es, zu verstehen, wie man mit Hilfe des Factory-Method-Patterns  
die Objekterzeugung kapselt und erweiterbar macht – etwa für unterschiedliche  
Dateiformate oder Ausgabemedien (Datei, Konsole).

---

## ⚙️ Features
- Lesen von Artikeldaten aus einer **CSV-Datei**  
- Schreiben der Artikeldaten in eine **TXT-Datei**  
- Alternativausgabe auf der **Konsole**  
- Umsetzung des **Factory-Method-Patterns** mit abstrakten und konkreten Klassen  
- Verwendung objektorientierter Konzepte (Abstraktion, Polymorphie, Kapselung)
